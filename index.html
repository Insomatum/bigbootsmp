Mit Java Edition

Für Minecraft Java auf Windows, Mac und Linux.

  1. Starte Minecraft Java Edition und wähle im Launcher Version 26.3.
  2. Klicke auf Mehrspieler und dann auf Server hinzufügen.
  3. Name: Big Boot SMP. Bei Serveradresse kommt die IP von rechts rein.
  4. Auf Fertig klicken, Server auswählen, Server beitreten. Willkommen an Bord.

Verbindungsdaten

bigbootsmp.my.pebble.host

Veraltete Version? Stell im Launcher unter Installationen die Version 26.3 ein.

Mit Bedrock

Für Minecraft auf Windows (Microsoft Store), Handy und Tablet.

  1. Starte Minecraft und tippe auf Spielen.
  2. Öffne den Tab Server und scrolle nach unten zu Server hinzufügen.
  3. Name: Big Boot SMP, dazu Serveradresse und Port von rechts.
  4. Speichern, Server unter «Zusätzliche Server» antippen und Server beitreten.

Verbindungsdaten

bigbootsmp.my.pebble.host
19132

Klappt nicht? Aktualisiere Minecraft. Mit einer alten Bedrock-Version scheitert die Verbindung oft.

Mit PS5, Xbox oder Switch

Auf Konsolen kann man keine eigenen Server eintragen. Die Gratis-App BedrockConnect auf deinem Handy löst das: Sie zeigt den Server im WLAN an, und deine Konsole findet ihn dann in der Weltenliste.

  1. Lade BedrockConnect aus dem App Store oder Google Play Store aufs Handy.Für die Switch brauchst du ein iPhone oder iPad.
  2. Handy und Konsole ins selbe WLAN.Mobile Daten, VPN oder Gäste-WLAN funktionieren nicht.
  3. In der App den Tab Custom öffnen und unten rechts auf das blaue + tippen. Name, IP und Port von rechts eintragen und Save tippen.
  4. Den Server antippen und auf den blauen Start-Knopf drücken. Er wird rot und zeigt «Stop», sobald es läuft.In der Gratis-Version kommt vorher kurz Werbung. Auf dem iPhone die Frage nach dem lokalen Netzwerk mit OK bestätigen.
  5. Auf der Konsole Minecraft starten. Der Server steht jetzt in deiner Weltenliste. Antippen, und du bist drin.

Plugins

Was der Server extra kann

Wähle ein Plugin, um zu sehen, wie es funktioniert. Weitere kommen dazu.

Braue dein eigenes Bier

Mit BreweryX entstehen Bier, Wein, Met und Schnaps so ähnlich wie in echt: kochen, brennen, im Fass reifen lassen. Wer das Rezept genau trifft, bekommt bessere Qualität, sichtbar an den Sternen auf der Flasche

Zutaten, Kochzeit, Anzahl Brennvorgänge und Holzart des Fasses entscheiden, was am Ende rauskommt.

Kochen

Immer nötig
  • Kessel auf Feuer, Lava, Magmablock oder Lagerfeuer stellen.
  • Mit Wasser füllen und Zutaten per Rechtsklick reinwerfen.
  • Rechtsklick mit einer Uhr zeigt die Kochzeit.
  • Fertig? Mit leeren Glasflaschen abfüllen.

Destillieren

Je nach Rezept
  • 1 Glowstone-Staub oben in den Braustand. Er wird nicht verbraucht.
  • Flaschen unten einsetzen.
  • Ein Durchgang dauert etwa 40 Sekunden.
  • Über die Flasche hovern zeigt, wie oft sie gebrannt wurde.

Lagern

Je nach Rezept
  • Flaschen in ein Fass legen, Rechtsklick öffnet es.
  • 1 Jahr Reifung dauert 1 Minecraft-Tag, also 20 Minuten.
  • Bei manchen Rezepten zählt die Holzart.

Kleines Fass

9 Flaschen
  • 8 Holztreppen als 2×2-Block.
  • Schild mit «Barrel» unten rechts.

Grosses Fass

27 Flaschen
  • 4×4 aus 20 Planken und 16 Treppen, gleiche Holzart.
  • 1 Zaun als Zapfhahn, dazu ein Schild mit «Barrel».
Richtig gebaut, wenn im Chat «Barrel created» steht.

Drei Rezepte zum Einstieg

Ein einfaches, ein mittleres und ein schweres. Alle weiteren findest du im Rezeptbuch.
